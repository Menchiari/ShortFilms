# Reference clips, draft 9

One clean clip per 3D shot of animatic d9 (`<SCENE>_<SHOT>.mp4`, 24 fps, 1120x480): no labels, no subtitles, no faces
(close shots were rendered with `SHAPE_SLITS=0`). Text-card shots have no clip.

Use: name the clip and its job in the prompt ("Video 1: camera movement and blocking only"). Seedance treats reference
videos as semantic: the prompt says which part to take. Recommended reference length is 5 to 10 s; for shorter shots,
use the clip as it is or join it with its neighbour from the same take.
